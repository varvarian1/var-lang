# VAR Language Interpreter

### Requirements

CMake 3.10 or higher
C++17

### Build
 
```bash
git clone https://github.com/yourusername/var-lang.git
cd var-lang
mkdir build
cd build
cmake ..
cmake --build .
```

### Usage
You can run test programs in examples
```bash
cd output
./var ../examples/first-program.var
```
